# Perfil do Usuario — NVDAStudio

## Preferencias
- Idioma: Portugues-BR
- Editor: VS Code Insiders, Cursor
- Sistema: Windows 11 + WSL2
- Commits em ingles (feat:, fix:, chore:, etc.)
- Python: mypy strict, sem from __future__ import annotations
- TypeScript: strict mode, sem any implicito

## Comportamento
- Explica ANTES de executar — nunca age sem confirmacao explicita
- Tom direto, amigavel, sem enrolacao
- Um terminal por processo
- Matar processos por PID, nunca por nome generico
- Nunca duplicar logica — sempre verifica se ja existe antes de criar
