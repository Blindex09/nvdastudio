NVDAStudio

NVDAStudio is an NVDA add-on that creates, reviews, documents, packages, and iterates other NVDA add-ons using AI via the Groq API. It provides an accessible interface built with wxPython, running entirely inside NVDA.

Requirements

  • NVDA 2025.3.3 or later
  • A Groq API key (free tier available at console.groq.com)
  • Internet connection for AI generation

Installation

Double-click the .nvda-addon file, or use NVDA menu → Tools → Add-on Store → Install from file.

Configuration

  1. Open NVDA Settings with NVDA+N then P.
  2. Navigate to the NVDAStudio category.
  3. Enter your Groq API key in the designated field.
  4. Optionally, set an output folder for generated add-ons.
  5. Press OK to save.

Alternatively, press NVDA+Shift+, to open NVDAStudio settings directly.

Usage

Opening NVDAStudio

Press NVDA+Shift+N to open the NVDAStudio dialog. NVDA will also announce "NVDAStudio ready" approximately 1.5 seconds after startup.

Creating an Add-on

  1. Press NVDA+Shift+N to open NVDAStudio.
  2. Describe what your add-on should do in the text field.
  3. Press Create Add-on. The AI pipeline will clarify requirements, plan, generate code, review it, and package it.
  4. The generated .nvda-addon file will be placed in the configured output folder.

Pipeline Stages

When you request an add-on, NVDAStudio runs the following autonomous pipeline:

  1. Clarify — The AI asks clarifying questions to understand your requirements.
  2. Plan — A structured plan is created with modules, gestures, and events.
  3. Generate — Python code is generated for each module according to NVDA standards.
  4. Review — The critic agent reviews the code for correctness and accessibility issues.
  5. Package — The add-on is bundled into a .nvda-addon file ready to install.

Troubleshooting

API key not accepted
Verify the key at console.groq.com/keys. Use the Validate Key button in NVDAStudio settings.
Generated add-on fails to install
Check the NVDA log (NVDA+F1) for details. Common causes: invalid manifest fields or Python syntax errors in the generated code.
No output folder configured
The add-on defaults to the user's Documents folder when no output path is set.
