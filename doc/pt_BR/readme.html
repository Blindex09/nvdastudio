NVDAStudio

O NVDAStudio permite conversar com uma IA agêntica para criar, revisar e empacotar addons do NVDA.

Como abrir

Pressione NVDA mais Shift mais N. Para abrir as configurações, pressione NVDA mais Shift mais vírgula.

Configuração

Escolha o provedor, mantenha Alto para o roteamento automático e informe a chave de API do provedor. A validação é feita em segundo plano para não bloquear o NVDA.

Conversa e criação

Descreva o addon em linguagem natural. A IA pode fazer perguntas necessárias, apresentar um plano para aprovação, executar as etapas e oferecer o pacote final. O raciocínio interno não é colocado no histórico.

Acessibilidade

A interface usa controles nativos, ordem lógica de tabulação, foco previsível e mensagens em texto simples. Checkpoints aguardam uma decisão explícita do usuário.

Instalação do resultado

Abra o arquivo com extensão nvda-addon e confirme a instalação no NVDA. Reinicie o NVDA depois da instalação para carregar a nova versão.
